# Changelog

## 0.2.0 — 2026-11-09

- Add complete signed prime families and consensus terms for nonmonotone models.
- Add FV, RAW, RRW and SCRAM DIF with explicit ratio states.
- Add scoped Open-PSA MEF static import/export and XML CLI commands.
- Compare 256 Boolean functions against a truth-table oracle and add an independent SCRAM CI gate.

## 0.1.0 — 2026-11-01

Initial independent MoonFault release. Public MoonBit API, bounded JSON bridge, offline Node CLI, three worked scenarios, independent reference-model tests, workspace consumer and four-backend GitHub CI.
