# Development and attribution

This is a new project for the November 2026 development cycle. It is not a rename or resubmission of MoonConfig, MoonGED, MoonPURL or MoonStory. AI assisted implementation and test generation; contributors should understand and review the contracts and counterexamples before submitting to a competition.

We first prototyped resource reservations and fuzzy linkage locally, then found substantial overlap with cauchyQ/moonbit-slotplan and didiLjf/moon-record-linkage. Neither prototype is part of this repository or this entry. The published project has its own algorithms, inputs, examples and tests.

Public GitHub repository metadata searches on 2026-11-01 included `language:MoonBit "fault tree"`, `reliability / BDD`. No direct matching project was found by those searches. This is a documented search, not a claim of exhaustive ecosystem uniqueness. Related results and concrete differences are in contract.md.

Development history records implementation, reference tests, scenario assertions, public consumer and reproducible delivery as meaningful commits. There are no empty commits or generated bulk test-case commits used to pad the count.
