# MoonFault 0.3.0 复审进度与验证说明

2026-11-14。仓库：https://github.com/forey217/moonfault

## 本轮实际实现

在完整 MEF 交付计划基础上，新增 27 种数学运算、布尔比较、ite/switch 条件分支，以及显式参数的指数、GLM、Weibull 概率函数。运算可组合、引用参数，并通过既有作用域和共享事件逻辑参与故障树分析。导出保留原表达式，不把模型换成一组不可追溯的结果数字。

这次同时补充了错误检查与数值处理：未选中分支仍检查语法、引用和参数循环；条件分支按需求值；整数字面量扩展到精确 binary64 范围；算术中间值溢出、非法函数域和错误参数类别明确报错。极小概率与极大时间/失效率采用稳定公式处理。

## 可复核案例与证据

运行 `node scripts/cli.mjs mef-analyze examples/mef/lifetime.xml`：工作条件 2、时长 100，三个基础事件概率分别为 0.0198013266932447、0.019549266552605832、0.008067283394428835，顶事件概率约 0.046716445696。该案例已做独立公式对照及 XML 往返验证。

23 组 MoonBit 和 17 组 Node 测试覆盖新旧能力。新报告包括 27 种数学运算的 98 项对照、三种时间函数的 211 项对照、条件与错误输入，以及任务时长场景。保留 240 个随机 DAG 和全部 256 种三变量函数的独立参考验证。CI 在四后端运行，并将显式时间指数模型加入 SCRAM 对照；实际运行记录以此次提交的 Actions 结果为准。

## 未完成内容仍明确保留

0.3.0 只是在完整交付路线上的新阶段，不是整套标准一致性完成版。标准任务时间上下文、单位转换、周期测试、随机采样、外部函数、四类 CCF、替换规则、事件树、多文件及报告读写仍需继续实现和独立验收。现有三种时间函数接收显式且单位一致的数值参数，并不等同于上述未完成功能。

新的申报书、完整计划、当前能力说明和软件包版本保持一致。申请依据新版目标、当前成果及后续验收安排重新审核，而不是把计划当成已完成结果。
