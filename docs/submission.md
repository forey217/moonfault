# MoonFault 项目申报书

## 1. 项目名称
MoonFault：Open-PSA MEF 2.0 概率安全分析与模型交换库。

## 2. 项目简介
使用 MoonBit 开发可独立安装的模型读写与分析库。项目最终交付承诺完整实现 Open-PSA MEF 2.0 明确定义的结构及语义，覆盖故障树、随机表达式、元逻辑、事件树、模型组织与结果交换，不以静态子集作为项目终点。当前 0.2.0 为阶段成果，完整实现尚未完成。

## 3. 项目方向与通用性
基础工具库 / 数据处理。以 MoonBit API 和离线 XML/JSON 命令行复用，服务模型迁移、可靠性教学、系统故障分析和分析结果复核。

## 4. 三个完整使用场景
1. 共享电源分析：输入电源和两台服务器的固定失效概率，保留共享事件身份，输出顶事件概率 0.02245、最小割集及电源 RRW 8.98，用于比较改进方案；已实现。
2. 非单调切换分析：输入模式控制的两个分支，输出概率 0.34、含负文字和共识项的素蕴含项及重要度，用于解释条件切换影响；已实现。
3. 跨工具模型复核：读入多文件 MEF，解析时间分布、共因失效及事件树指令，输出序列/后果结果并导出模型与报告供另一工具复核；当前完成静态模型往返，完整流程列入最终交付。

## 5. 核心交付与验收
保留 ROBDD 概率、Birnbaum、FV、RAW、RRW 及带符号素蕴含项；补齐时间与随机表达式、四类 CCF、替换规则、事件树、任务阶段、跨文件引用及报告读写。按标准逐项关联实现、合法/非法输入、语义往返与独立数值对照；必需项未完成不得宣布全标准通过。外部函数通过显式宿主接口接入；标准未定事项单列解释与案例。详见仓库完整实现与验收计划。

## 6. 原创与参考
分析算法与 MEF 映射为原创 MoonBit 实现，MIT；参考 Open-PSA 2.0、Bryant ROBDD 和 SCRAM，XML 层复用 Milky2018/xml 0.5.0（Apache-2.0），并非 SCRAM 移植。

## 7. 当前验证
0.2.0 已有 19 组 MoonBit、11 组 Node 测试及四后端 CI；4 个静态案例与 SCRAM 对照通过。这些证据仅对应当前实现，不能代替后续完整标准验收。
