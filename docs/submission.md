# MoonFault 项目申报书

## 1. 项目名称
MoonFault：Open-PSA MEF 2.0 概率安全分析与模型交换库。

## 2. 项目简介
使用 MoonBit 开发可独立安装的模型读写与分析库。最终交付承诺完整实现 Open-PSA MEF 2.0 明确定义的结构及语义，覆盖故障树、随机表达式、元逻辑、事件树、模型组织与结果交换，不以静态子集作为终点。当前 0.3.0 为阶段成果，完整实现尚未完成。

## 3. 项目方向与通用性
基础工具库 / 数据处理。以 MoonBit API 和离线 XML/JSON 命令行复用，服务模型迁移、可靠性教学、系统故障分析和分析结果复核。

## 4. 三个完整使用场景
1. 共享电源分析：输入电源和两台服务器的固定失效概率，保留共享事件身份，输出顶事件概率 0.02245、最小割集及电源 RRW 8.98，用于比较改进方案；已实现。
2. 非单调切换分析：输入模式控制的两个分支，输出概率 0.34、含负文字和共识项的素蕴含项及重要度，用于解释条件切换影响；已实现。
3. 任务时长分析：读入工作条件和显式时长 100，计算指数失效、GLM 修复及 Weibull 磨损，输出顶事件概率约 0.046716445696；导出再导入保留公式和结果，便于复核；已实现。

## 5. 核心交付与验收
已实现 ROBDD 概率、重要度、带符号素蕴含项、27 种数学运算、条件表达式及三种显式时间概率函数。继续补齐单位与任务上下文、随机采样、周期测试、四类 CCF、替换规则、事件树、跨文件及报告读写。逐项关联实现、正反例、语义往返和独立对照；必需项未完成不得宣布全标准通过。外部函数接入宿主接口；标准未定事项单列解释。详见完整实现与验收计划。

## 6. 原创与参考
分析算法与 MEF 映射为原创 MoonBit 实现，MIT；参考 Open-PSA 2.0、Bryant ROBDD 和 SCRAM，XML 层复用 Milky2018/xml 0.5.0（Apache-2.0），并非 SCRAM 移植。

## 7. 当前验证
0.3.0 配套 23 组 MoonBit、17 组 Node 测试及四后端 CI，新增 98 项数学运算和 211 项时间函数对照；SCRAM 另验共享支持的模型。这些证据对应当前实现，不能代替完整标准验收。
