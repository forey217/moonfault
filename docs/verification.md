# Verification

MoonBit `0.10.15+943464bfa`, Moon `0.1.20261012` and Node.js 24. The workspace contains 23 MoonBit tests including three public-API consumer tests. CI checks JS, Wasm GC, Wasm and Linux native. Seventeen Node test groups cover 240 seeded coherent DAGs and all 256 three-variable Boolean functions. The signed reference independently examines 6,912 ternary cubes for sufficiency/deletion minimality and compares 768 risk rows against complete assignment summation. It also checks consensus terms, bit 63, zero denominators, negative importance, resource budgets and MEF validity/round trips.

`npm run verify` regenerates the reports. `python3 scripts/scram_compare.py` invokes the independent SCRAM executable installed in Linux CI. It validates MoonFault's XML output and compares top probability, signed products, Birnbaum, FV (SCRAM CIF), DIF, RAW and RRW. CI uploads the actual SCRAM XML and `scram-interop.json`. Decimal comparisons allow SCRAM's XML output rounding; the exhaustive signed oracle uses 1e-12 tolerance.

Tests demonstrate the declared static analysis and explicit-expression profile. They do not certify all MEF models or real-world input data.

The single-component exponential fixture has Q>0 and Q0=0. MoonFault reports infinite RRW, while SCRAM 0.16.2 leaves a zero sentinel ([reference implementation](https://github.com/rakhimov/scram/blob/0.16.2/src/importance_analysis.cc)). The comparison asserts both behaviors and records a `boundaryDifferences` entry; it does not claim those values are equal. All finite importance values, probabilities and prime families are compared normally. Failure artifacts are retained for diagnosis.

The 0.3.0 implementation adds 98 numerical-operation comparisons, 211 lifetime-function comparisons, conditional/invalid-branch checks and a worked lifetime scenario. Reports distinguish scalar conversion policy from full unit/type conformance. The SCRAM suite now includes the explicit-time exponential model. Remaining MEF layers must acquire their own positive, negative, round-trip and semantic reference cases before the project can claim full implementation; see [the acceptance plan](mef-roadmap.md).
